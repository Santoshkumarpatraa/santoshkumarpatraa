02 About

I work across the stack, with most of my depth on the server side. Day to day that means REST APIs, multi-datastore data flows, third-party integrations and the background jobs that keep them consistent — then the front-end work to put that behind something usable.

Day to day that means PostgreSQL, MongoDB, Redis and Elasticsearch behind Node.js and Sails.js services, deployed on AWS with Docker and EKS. I've built authentication, payment and tax integrations, real-time WebSocket features, and scraping and ingestion pipelines that have to degrade gracefully when an upstream site changes overnight.

I like owning a feature end to end — schema and API design, the interface on top, tests, rollout, then the dashboards and alerts that tell me whether it actually worked. Most of my best work has been unglamorous: making something that already existed measurably faster, cheaper or harder to break. This site is a small example — hand-built, no framework, no dependencies.
